What the bundle changed

mechanism 1

Cheaper matcher / scoring loop

Hot-path scoring dropped per-match allocation and repeated work: zero-alloc filename checks, byte walks for the distance penalty, max_path_len computed once per fuzzy pass, memset skipped before read, and the per-match scoring loop parallelized.

e85b9c1 · b85c731 · 6e367ec · fba573a · c26c04f
mechanism 2

Less IO

Binary sniff no longer reads text files all the way to EOF, and the 8M-String re-sort was removed. Less bytes touched per op shows up directly as lower Read B/op and fewer faults on the same warm index.

040e1bb
mechanism 3

Parallel work-estimate dispatch

Fuzzy match uses a work-estimate thread dispatch instead of collapsing 4-thread searches to 1, so 4T runs actually fan out. Combined with the parallel scoring loop this is where 4T CPU/wall separation comes from.
